# 骨架纪律

这份说明只给本仓的粗选骨架用。它摘的是品味和设计技能里反复出现的反模板想法，改写成可以执行的拒绝条件。这里不内置那些技能，也不做运行时打分。

生成器只做机械检查：结构是否彼此不同、内容槽是否锁住、骨架哈希是否对得上、关系是否成立、有没有外链。好不好看仍然要人看。

## 生成时必须拒绝

- 三个候选去掉颜色之后结构签名相同。换 token 不是一个新方向。
- 三页的 title / subtitle / 3 条要点 / cta / foot 有任何一页不一样。
- 页面读不出这些内容槽，或文档标题和主标题不一致。
- 声明的 `skeletonHash` 和骨架文件不一致，或页面结构签名和该文件不一致。
- `lineage` 不同族，或同族里 variant 重复。
- `contrast` 没有在同一条轴上覆盖 low / mid / high，或没有跨至少 2 个 family。
- HTML 里出现外链、`@import`、脚本拉取、`localStorage`，或渲染后还留着 `{{`。

writer 不写 decide，也不自己写台账。只有 `add` 落账。

## 反模板

下面这些是默认值，不是禁绝一切卡片或一切居中。简报点名要的骨架可以用；生成器不许把它们当成偷懒的通用皮。

- 不要用三张等大的「图标 + 标题 + 两行字」当整页。`brutal-cards` 是被点名的硬边分卡，其他骨架不要长成它。
- 不要在标题上再加眉题。标题自己要有重量。
- 不要渐变字、玻璃模糊、紫蓝光晕。强调靠字号、字重和一块明确的颜色。
- 不要用中点把三个词串成装饰行，不要给每个动作加箭头尾巴。
- 首屏是论点，不是一排指标。
- 留白是结构。`minimal-band` 的空是横带下面的安静，不是没做完。
- 一页一个主动作。内容槽里的 cta 是那个动作，不要再发明第二句文案。
- 编号只有在顺序本身有用时才出现。窄带骨架不用编号。

## 不做的事

- 不把 Figma 转成 HTML。
- 不把外部 skill 的仓库或运行时拷进本包。
- 不做自由生成。brief 只填进已经定好的槽。
- 不收未清洗的社区整页。新骨架若要借用 MIT 结构，先写进 `NOTICE.md`：来源、许可证、改了什么。
