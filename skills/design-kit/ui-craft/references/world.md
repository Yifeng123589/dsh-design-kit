# 世界：先决定这是什么世界，再决定它长什么样

何时读我：手上有一个页面、一次改版，或者开会时那句「这个界面该长什么样」还没有答案的时候。先读我定方向，再用 [craft-floor.md](craft-floor.md) 验收；[modes.md](modes.md) 告诉我这一屏要访客做成什么事，方向必须服务那件事。

方向不是选风格。风格是别人做过的成品的名字（极简、瑞士、新粗野），世界是这一页所属的那套材料、场所、印刷物和仪式。风格可以套在任何产品上，世界只能长在这个产品上。

## 1 先判读：手上是哪一种工作

动手前回答一句：这个界面是从零开始，还是已经有一个世界，我只是加一页。

| 工作类型 | 判别 | 必须保留 | 产出 |
|---|---|---|---|
| 重构 | 有产品与品牌，视觉世界过时或失控 | 产品事实、内容、功能、明确的品牌承诺 | 换掉整个世界，不是打磨旧皮 |
| 已有体系内扩展 | 代码里有稳定的 token、组件、语气 | 既有世界，除非用户批准改系统 | 只解决新页面的目的、内容、层级、状态 |
| 全新世界 | 没有可继承的视觉权威 | 用户已确认的事实与资产 | 一句话机制 + 7 个候选 + 方向契约 |

三条边界：

- 重构不保留旧视觉。旧样子是「这个产品是什么」的证据，不是「它该长什么样」的权威。用户说「保留现在的蓝」，那是品牌承诺，保留。
- 扩展不发明新身份。一个页面、一个组件、一个空状态，继承它所在的世界，不要顺手做一次品牌重塑。
- 缺 DESIGN.md 不等于没有体系。代码里的 token、组件、真实文案、素材、和已经上线三年的页面就是体系。先把它们读出来写成文档，再决定扩展还是重组；不要因为文件不存在就宣布「从零开始」。

反例：登录页改版，重做了按钮、卡片、留白，导航与品牌色一字不改，交付时叫「V2」。这既不是重构也不是扩展，是一次没有结论的打磨。
正例：同一张登录页，先读现有 token 与首页，写下「既有体系 = 深绿 #0F3D2E + 直角 + 无衬线 + 2px 描边」；判定为扩展，只改表单区结构与错误态，其余不动。

## 2 只问 2 到 3 个真正改变结果的问题

问题池固定四类，挑与这次工作最相关的两三个，一次问完：

1. 谁要看：具体角色，不是人群画像。
2. 要相信什么，或要完成什么。
3. 什么算成功：能观察到的结果，不是「好看」。
4. 什么不能动：品牌承诺、合规、既有组件、必须出现的字段。

| 坏问题 | 为什么坏 | 换成 |
|---|---|---|
| 你喜欢简约还是活泼 | 要风格偏好，答案不可执行 | 交班前 10 分钟医生打开它，一屏内必须看到什么才敢签字 |
| 主色想要什么颜色 | 跳过策略直接进 HEX | 这页出现在白班走廊的强光下还是夜班值班室 |
| 参考哪家 | 把决定外包给竞品 | 上次排班看错导致过什么后果，哪个字段最容易看错 |
| 要不要加点动效 | 设备先于理由 | 这一页上一个动作做完，用户下一步该去哪 |

反例：问「你想让这个页面给人什么感觉」，得到「专业、高级、有科技感」，三个词能套到任何产品，等于没问。
正例：问「医生在换班前 10 分钟打开它，看到的第一眼应该是什么」，得到「这一屏有几处冲突、分别是哪两班」，首屏结构和数据优先级当场就定了。

## 3 一句话机制

格式固定：「给 <谁> 在 <什么场景> 用 <独特机制>，它属于 <文化世界>，这一页要证明 <一句>。」五段缺一段，方向就还没成形。

- 排班工具：「给三甲医院呼吸科的值班主任在换班前 10 分钟用冲突检测排班表，它属于医疗交接班的白板与交班本传统，首页要证明冲突能在一屏内被看见。」
- 手工皮具：「给愿意花两千元买一只包的上班族在门店第一次摸到皮料时用创始人的裁皮记录，它属于欧洲工坊的裁料纸样与钢印传统，首页要证明这只包有具体的人在亲手做。」

反例：「一个现代、简洁、可信赖的 SaaS 工具」。三个形容词加一个品类，任何产品都能用，它连「给谁」都没有。

## 4 列 7 个候选世界

从受众的文化世界里找具体的视觉体系、物件、场所、仪式、出版物、图形传统。不要从「这个品类默认长什么样」出发，那个默认样子在下面单独列出，只进排除项。每条写两句：为什么共鸣，长什么样（地面与主色、字体性格、一个签名特征）。

- 为什么共鸣：这个物件在受众的生活里承担什么，为什么它能承载机制，而不是「看起来很像这个行业」。
- 长什么样：足以让一个没读过简报的工程师画出草图。写不出这三样，这条是情绪不是世界。
- 排序：按共鸣强弱排，第 1 条是你的推荐。

以「面向医生的排班工具」为例，7 条候选（材料家族标在括号里）：

1. 科室交班白板（现场书写）：每天所有变更都先写到这块板上，擦掉再写是它的语法。白板白 #F7F8F6 带轻微擦痕，记号笔黑 #1C1C1C 加改班红 #B3261E；手写窄体无衬线；签名特征是擦除后的淡灰残影表示上一版。
2. 护理交班本 / SBAR 记录（印刷表单）：字段密集、逐行签名的表格传统。米黄表格纸 #FBF8EF，蓝黑墨水 #1F3A5F 加印章红 #C0392B；窄体等宽标注配手写风副标；签名特征是每行末尾的签名位与时间戳双栏。
3. 机场出发牌 / 翻牌屏（公共信息屏幕）：状态位一次只翻一格，远距离可读。深炭 #16191D 配琥珀 #F2A900；等宽大写；签名特征是翻牌式状态位，改班时整行翻一次。
4. 地铁线路图（图形传统）：用线路与站点表达连续与换乘。纸白 #FAFAF7 底，线路色 #1F5FA8 / #B3261E / #2E6B5E 承担分类，人文无衬线；签名特征是每条值班线画成一条横线，站点是被排的人，换乘站是兼岗。
5. 剧院节目单（出版物）：场次与卡司双栏，替补单独标记。米白 #F4EFE6，深酒红 #6B1F2A 配金 #C6A15B；衬线标题配小字斜体角色说明；签名特征是「替补」的小号角标。
6. 药房药袋标签（热敏标签）：小面积、强约束、必须有时间戳。标签白 #FDFDFB 底，蓝字 #1F4E9C 加红色警示 #C22B20；无衬线粗体配极小的免责附文；签名特征是右下角的时间戳方框（谁、何时、第几版）。
7. 手术室磁贴排程板（磁贴材料）：可拖动、可占位、冲突时物理上放不下。不锈钢灰 #D8DADC 加手术室绿 #2E6B5E；标签机字体，窄体大写；签名特征是磁贴拖动与冲突位闪边框。

列表纪律：

- 至少跨 3 个材料家族（上例跨了书写表面、印刷表格、公共信息屏、标签材料四个）。同族超过 3 条，说明推导停在了这个主题最显眼的那个物件上，退回去重找。
- 近重复只算一条。上例第 1 与第 7 只差磁贴，合成一条，再补一条新的。
- 操作页与阅读页的候选来自受众世界的图形、场所、仪式、物件，不能来自受众操作的仪器。把终端、监护仪、控制台直接搬上工作界面，是这个工具的戏服，不是它的世界。
- 说服页与体验页可以用受众操作的工具，但只准花一条候选。

排除项写在候选列表之外，先固定下来：**这个品类一定会出现的默认样子**，以及它可预期的反面。

- 排班工具的默认样子：深色仪表盘 + 蓝紫渐变 + 卡片网格 + 大数字 KPI 环 + 左侧图标栏。
- 它的反面：浅灰底 + 圆角白卡 + 一个主色按钮 + 「更清爽」的留白。
- 两条都进排除项。默认样子是被品类决定的，反面是被「避开默认」决定的，两个都不是为这个产品做的决定。

## 5 AI 陈词滥调清单

这四组是训练数据里最密的落点。它们不脏，脏的是自由轴上仍然落进来。

| 组合 | 具体长相 | 可以用 | 算失败 |
|---|---|---|---|
| 暖米色 + 高对比衬线 + 赤陶 | #F5EFE4 底，Playfair 或 Fraunces 大标题，强调色 #C2674A | 简报点名手作、料理、婚礼、纸质刊物，且正文真的以长文为主 | 只要出现「温暖」「人文」「有质感」就自动落地 |
| 近黑 + 霓虹描边 | #08090B 底，一条 #00FF9D 描边，`0 0 24px` 彩色光晕 | 产品本身是演出、游戏、加密、夜店，或简报点名赛博 | 把「科技感」当成使用场景，默认上这套 |
| 大报编辑风 | 1px 发丝线网格，斜体衬线大标题，10px 字号 0.18em 字距的等宽小标签 | 媒体、专栏、文化机构，且阅读是唯一任务 | 出现在需要点按钮完成任务的工具页上 |
| 平涂高饱和 + 黑盒 + 硬阴影 | #FF4D2E 平涂，纯黑卡片，`4px 4px 0 #000` | 简报点名新粗野或海报风，页面真的以海报为主 | 任何要表达「高级」或需要填写表单的页面 |

判断法只有两问，遮住 logo 和产品名再问：

1. 旁人猜得出品类吗？猜得出就是陈词滥调。
2. 猜出品类后，再猜「它刻意避开了什么」，还猜得中吗？猜中也是陈词滥调，反向的也算：为了不像科技公司而上米色衬线，同样是被品类决定。

两问都猜不中，才算站在自由轴上做了决定。品类被反复设计得越狠，这两问越准。

## 6 字体：先用黑名单

这些是训练数据默认字体，出现即需交代：Fraunces、Playfair Display、Cormorant、Lora、Crimson、Newsreader、Syne、Space Grotesk、Space Mono、IBM Plex、Inter（作展示字体时）、DM Sans、DM Serif、Outfit、Plus Jakarta Sans、Instrument Sans。

规则：想用其中任何一个，写一句「别的字体为什么做不到」的具体理由。

- 可用理由：「正文用 Inter，因为中文回退到苹方时 x-height 最接近，混排不跳。」（仅限正文，不作展示字体）
- 无效理由：「主题联想」。书想要衬线、书店想要手写体、科技想要等宽体，这三条正是黑名单存在的理由。主题联想不是理由，是默认。

操作页用系统栈与工作马字体即可；说服页与体验页才需要带观点的展示字体。字体栈、中文字体与字阶见 [type.md](type.md)，配色策略见 [color.md](color.md)。

## 7 方向契约六字段

选定方向后，动手写样式之前，六个字段全部写出来，每个字段一句话到三句话。

| 字段 | 写什么 | 例（手工皮具品牌官网） |
|---|---|---|
| THESIS | 这一页独占的一个想法，以及它拒绝的品类默认排布 | 页面是一张摊开的裁料纸样，拒绝「大图 + 三卖点 + 加购」的电商首屏 |
| OWN-WORLD | 色彩与组件语言，删掉全部内容还能认出 | 牛皮纸 #D9C7A7 作地面，钢印深棕 #3B2A1E 作文字，切口露出的原色皮革作强调；组件一律直角、1px 描边 |
| STORY | 访客依次理解、相信、做什么 | 先看到一张纸样上的手工编号，再读到「谁裁的、哪天裁的」，最后去约一次到店 |
| FIRST VIEWPORT | 精确构图：什么在哪、多大、主动作在哪 | 左 62% 是带编号的裁料纸样大图，右侧竖排 3 行工序说明，底部一枚「预约到店」文字按钮 |
| FORM | 选中的形式，在 7 条里的位置 | 第 2 条「工坊裁料纸样」，位置 2/7 |
| FINISH | 退出条件：缺哪一件，这一版就不算完成 | 两轮审阅、修复结论、DESIGN.md、每个素材的来源，缺一件都不算交付 |

同一套字段填给医生排班工具，可以直接抄结构：

```text
THESIS: 排班表就是一块会被擦写的交班白板，拒绝仪表盘式的 KPI 环与卡片网格
OWN-WORLD: 白板白 #F7F8F6 地面，记号笔黑 #1C1C1C 与改班红 #B3261E；直角、2px 手绘感描边
STORY: 先看到这周有 3 处冲突，再看到每处冲突牵涉哪两班，最后去改其中一处
FIRST VIEWPORT: 整屏是一张 7 天 × 4 班白板，冲突格叠加红框与残影，右上角「导出本周」文字按钮
FORM: 第 1 条「科室交班白板」，位置 1/7
FINISH: 两次审阅、修复批次、DESIGN.md、tokens 落地后才算交付
```

## 8 方向不是情绪：判断法与两条反例

三个测试，全过才是方向：

1. 删掉所有文案与图片，只剩色块、字距、留白，还能说出它属于哪个世界吗？
2. 能说出一个具体的场所或物件名字吗？「像医院」不行，「像交班白板」行。
3. 能指出一处只可能属于这个产品的细节吗？冲突格的残影、皮料纸样上的工序编号。

反例 A：「冷静、克制、专业、有呼吸感」。四个形容词，遮住行业可以套给银行、律所、SaaS、诊所，这不是方向，是语气。
反例 B：「深色 + 霓虹 + 玻璃」。有具体工艺，但遮住行业能套给任何一家 AI 公司；它描述的是训练数据的平均值，不是这个产品。

判断后的动作：方向过不了三问，不要加装饰救它，回到第 3 节重写一句话机制，再重列候选。

## 9 交付前检查

- [ ] 明确写出这次是重构、体系内扩展还是全新世界，并给出判据。
- [ ] 问过 2 到 3 个改变结果的问题，没有一个问题在问颜色、字体或风格偏好。
- [ ] 一句话机制五段齐全：给谁、什么场景、独特机制、文化归属、这一页要证明什么。
- [ ] 7 条候选每条都有「为什么共鸣」和「地面与主色 / 字体性格 / 签名特征」，跨至少 3 个材料家族，默认样子与四个陈词滥调组合都写进了排除项。
- [ ] 六个字段全部写出，每一条都能指出一个具体物件，而不是读完像心情描述。
