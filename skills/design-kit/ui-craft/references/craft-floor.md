# 底线：动手写第一行 UI 之前必读

何时读我：方向已定，准备写第一行样式之前读一遍；审阅时拿它当机械项的验收表（评分与脚本见 [audit.md](audit.md)）。这是地板，不是天花板，它保证页面不塌，不负责让它好看。

## 验收 Verify

逐条对照渲染结果，不是对照你的意图。一次渲染里全部看完，不要为每条规则单独截图。

- **对比度**：正文与占位符 ≥4.5:1，大字（≥24px，或 ≥19px 粗体）≥3:1，焦点环与图标 ≥3:1。彩色表面上的次级文字用同色相提亮或压暗，`oklch(from var(--accent) calc(l + 0.18) c h)`，不要用灰。
- **深度**：阴影有偏移也有柔化，从 `0 1px 2px` 到 `0 24px 48px` 有梯度。零偏移彩色光晕是装饰，不能用来表达层级；要装饰就承认它是装饰。
- **间距**：同组紧（4 到 12px），组间松（32 到 96px），标题上方空间至少是下方的 1.5 倍（常见做法 3 倍）。读计算后的值。
- **字体**：正文行宽 65 到 75ch（中文 30 到 40 字一行），展示字号上限 96px，字距下限 -0.04em。行高按文种取：中文正文 1.75 左右，西文 1.6，密集数据界面不低于 1.5。把真实文案灌进去，在 390 / 768 / 1440 三个宽度看溢出与断行。
- **动效**：一个有作者意识的时刻（首屏的主转变、列表的错位入场），不是每个区块同一套 fade-up。从 transform 与 opacity 起步，尊重 `prefers-reduced-motion`。
- **状态**：hover、disabled、loading、error、empty 五个都在，内容用真实数据而不是 `Lorem`。键盘焦点可见：`:focus-visible` 有 2px 以上轮廓。
- **浏览器表面**：你没画的地方也在做设计。`::selection`、`caret-color`、自定义滚动条、焦点环、`text-underline-offset`、表格里的 `font-variant-numeric: tabular-nums`。这是「真的做过」最便宜的证据。
- **文案**：控件说清动作（「导出 CSV」而不是「提交」），错误说清问题与恢复（「邮箱格式不对，形如 name@company.com」）。
- **覆盖**：简报里每一条要求都能在几秒内找到位置。

修正优先级：对比度、焦点、溢出属于必须修；间距、行宽、字距属于批量改一行 token 就能修；动效时刻与浏览器表面属于先留着，别在修 bug 时顺手扩大范围。

## 拒绝默认 Refuse

下面不是禁令，是品类的默认值。简报原文可以挣回任何一条；在自由轴上仍然顺手用了，说明你没在决定。

页面骨架：

- 等大的卡片（图标 + 标题 + 两行字）当页面结构。卡片是最省事的容器，卡片里再套卡片一定错。
- hero-metric 模板：大数字 + 小标签 + 一排辅助指标 + 强调色。
- 标题上方的 kicker / eyebrow（`kicker-eyebrow`）。这条是绝对禁令，没有简报能挣回它：标题自己要有重量，删掉标签。
- 章节编号 01 / 02 / 03，除非顺序本身携带读者需要的信息。
- 不需要打断、也不需要保护焦点的任务，用弹窗。

表面习惯：

- 渐变文字（`gradient-text`）。强调靠字重与字号。
- 装饰性玻璃模糊（`glass-decoration`）。`backdrop-filter` 只在一个具体效果需要它时才用。
- 卡片、列表项、提示条左侧 1px 以上的彩色竖条（`accent-border-bar`）。
- 非新粗野世界的硬偏移阴影，`box-shadow: 4px 4px 0`。
- emoji 或 Unicode 字符当图标系统（`emoji-icon`）。图标用一套真实图标库或自己画的 SVG，描边与字重统一。
- 等宽字体当「技术感」的服装，而不是给代码、数据、测量值。
- 模板装饰：用「·」把三个词串成一行（`设计 · 开发 · 交付`）、每个链接后挂「→」、整行全大写小字当装饰带。它们不承担信息，只是在冒充「设计过」。
- 用圆形、多边形或径向渐变遮罩假装有机轮廓，宁可不用。
- 按品类决定明暗（工具就深色、杂志就浅色）。按使用场景决定：谁、在哪、什么环境光。
- `transition: all`；`outline: none` 却不给替代焦点样式。

两组对照：

反例：后台列表页，五张等大卡片各放一个图标 + 标题 + 一句描述，标题上方 `MANAGEMENT` 小字，卡片左侧 3px 紫色竖条，卡片之间 16px 空隙。
正例：一张真实表格，按状态分组，行高 44px，表头右对齐并开 `tabular-nums`，筛选器只筛它作用到的那一列，空结果显示下一步动作。

反例：SaaS 官网首屏，48px 渐变标题 + 玻璃卡片 +「了解更多」，产品截图在第三屏。
正例：首屏直接放产品在工作中的样子（一次真实的冲突检测、一张排班结果），主动作就是产品里的那个动作本身：导入排班表、查看本周冲突。

## 一句话原则

底线只管机械项，不选方向；底线全绿之后，把页面花在已承诺的世界上；在「更精致」与「更坚决」之间犹豫时，选更坚决。

## 交付前检查

- [ ] 正文与大字对比度实测达标，彩色表面上的次级文字不是灰的。
- [ ] 五个状态、键盘焦点、真实文案都到位，390 / 768 / 1440 无溢出。
- [ ] 检查项里的绝对禁令零出现：kicker、渐变文字、彩色竖条、卡片堆砌、emoji 图标。
- [ ] 页面上至少有一个只属于这个世界的细节，而不是全绿之后就停手。
